# experiment-4

### Aim

To write a Python program to demonstrate various list operations such as appending, inserting, removing, popping, counting, finding the index, reversing, copying, extending and clearing elements in a list. The program also demonstrates built-in functions like `len()`, `max()`, `min()` and `sum()`.

### Algorithm

1. Start the program.
2. Create a list named `marks` containing student marks.
3. Display the original list.
4. Find and display the length of the list using `len()`.
5. Add a new element using `append()`.
6. Insert an element at a specific position using `insert()`.
7. Remove an element using `remove()`.
8. Remove the last element using `pop()` and display the updated list.
9. Count the occurrence of 100 using `count()`.
10. Find the index position of 50 using `index()`.
11. Reverse the list using `reverse()`.
12. Create a copy of the list using `copy()`.
13. Add multiple elements using `extend()`.
14. Find and display the highest value using `max()`.
15. Find and display the lowest value using `min()`.
16. Calculate and display the sum of all elements using `sum()`.
17. Clear all elements from the copied list using `clear()`.
18. Display the cleared list.
19. Stop the program.
